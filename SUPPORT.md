# Support

Open a [GitHub issue](https://github.com/ojaseminem/Pipeline-OS/issues) for bugs,
questions and feature requests. Include the Pipeline OS version (Settings → About),
operating system and CPU architecture, the screen or command you used, what you
expected, and sanitized logs. Never post credentials, tokens, private repository URLs,
client names, or proprietary project content.

Pipeline OS is pre-1.0 open-source software with no uptime or response-time
guarantee. Paid support may be offered independently but does not change public
issue priority or unlock closed features.

Security vulnerabilities, leaked secrets and artifact-integrity concerns are not
support requests. Report them privately as described in [SECURITY.md](SECURITY.md).

For installation problems, include the release tag, the installer file name, whether
the SHA-256 in `SHA256SUMS.txt` matched, and what the OS showed on first launch.
Installers are not yet signed by Microsoft or Apple, so a SmartScreen or Gatekeeper
prompt on first launch is expected (see the README's Download section).
